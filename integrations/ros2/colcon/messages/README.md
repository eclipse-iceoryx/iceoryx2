# Message Workspace

This directory contains a colcon workspace generating the Rust message crates
of the ROS 2 message packages the integration uses. The crates are generated
by `rosidl_generator_rs` and included by applications through the
[`ros-env`](https://github.com/ros2-rust/ros-env) crate, which provides the
generated messages of the sourced workspace.

`ros-env` includes only message crates generated by `rosidl_generator_rs`
0.5.0 or later. Older distributions may ship an older version, so instead,
the crates are generated fresh from the message definitions imported by
`<distro>.repos`.

All commands assume a **sourced ROS 2 environment**, e.g. inside the development
distrobox (see [../../README.md](../../README.md)), and are run from this
directory. `<distro>` is your ROS 2 distribution (`jazzy` or `humble`).

## Building

```bash
just setup integrations-ros2-messages
```

This imports the message definitions of `<distro>.repos` and builds the
crates into `../../target/<distro>/colcon/messages`.
Source its `install/setup.bash` to make the crates available.
